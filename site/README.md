# Vedro privacy policy

`privacy/index.html` contains the owner-approved public policy. Its deployed URL is
https://sivica.github.io/weatherapp/privacy/ .

GitHub Pages serves the dedicated `gh-pages` branch at `/`; that branch contains
only `.nojekyll` and `privacy/index.html`. This `site/` directory preserves the
same source alongside the app. Future policy changes require review and must
keep both copies identical; do not publish draft setup packets, build outputs,
logs or credentials to the site.

The app's Privacy policy button opens the public HTTPS page in the system browser.
It passes no weather query, location, credential or account information in the URL.
This policy publication does not complete Play setup declarations or submit the
app/store listing for review.
